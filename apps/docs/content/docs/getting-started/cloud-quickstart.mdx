---

这是开始使用 Multica 的最快方式，无需自建部署。

## 1. 注册

前往 [multica.ai](https://multica.ai) 创建账号。

## 2. 安装 CLI 并启动 daemon

把下面这段指令交给你的 AI agent（Claude Code、Codex、Gemini CLI、OpenClaw、OpenCode 等）：

```
Fetch https://github.com/multica-ai/multica/blob/main/CLI_INSTALL.md and follow the instructions to install Multica CLI, log in, and start the daemon on this machine.
```

也可以手动安装：

### macOS / Linux（Homebrew，推荐）

```bash
brew install multica-ai/tap/multica
```

### macOS / Linux（安装脚本）

```bash
# 安装 CLI
curl -fsSL https://raw.githubusercontent.com/multica-ai/multica/main/scripts/install.sh | bash
```

### Windows（PowerShell）

```powershell
irm https://raw.githubusercontent.com/multica-ai/multica/main/scripts/install.ps1 | iex
```

然后配置、认证并启动 daemon：

```bash
# 配置、认证并启动 daemon
multica setup
```

daemon 会自动检测 PATH 中可用的 agent CLIs（`claude`、`codex`、`gemini`、`openclaw`、`opencode`、`hermes`、`pi`）。当 agent 被分配任务时，daemon 会创建隔离环境、运行 agent，并把结果回传。

## 3. 验证 runtime

在 Multica web app 中打开你的工作区。进入 **设置 → Runtimes**，你应该能看到自己的机器作为 active **Runtime** 列出。

> **Runtime 是什么？** Runtime 是能够执行 agent 任务的计算环境。它可以是你的本地机器（通过 daemon），也可以是云实例。每个 runtime 都会上报可用的 agent CLIs，因此 Multica 知道该把工作路由到哪里。

## 4. 创建 agent

进入 **设置 → Agents**，点击 **新建 Agent**。选择刚刚连接的 runtime，并选择 provider（Claude Code、Codex、Gemini CLI、OpenClaw、OpenCode 或 Hermes）。为 agent 命名，这个名称会显示在看板、评论和分配关系中。

## 5. 分配第一个任务

从看板创建一个 issue（或使用 `multica issue create`），然后把它分配给新 agent。agent 会自动接手任务，在你的 runtime 上执行，并像真人队友一样汇报进度。

就这样，你的 agent 已经成为团队的一员。
