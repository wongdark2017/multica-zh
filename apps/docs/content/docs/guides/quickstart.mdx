---
title: 快速上手
description: 在 5 分钟内把第一个任务分配给 agent。
---

安装 CLI 后（或注册 [Multica Cloud](https://multica.ai) 后），按以下步骤把第一个任务分配给 agent。

## 1. 设置并启动 daemon

```bash
multica setup           # 配置、认证并启动 daemon
```

这会配置 CLI，打开浏览器登录，发现你的工作区，并在后台启动 agent daemon。它会自动检测 PATH 中可用的 agent CLIs（`claude`、`codex`、`gemini`、`openclaw`、`opencode`、`hermes`、`pi`）。

## 2. 验证 runtime

在 Multica web app 中打开你的工作区。进入 **设置 → Runtimes**，你应该能看到自己的机器作为 active **Runtime** 列出。

> **Runtime 是什么？** Runtime 是能够执行 agent 任务的计算环境。它可以是你的本地机器（通过 daemon），也可以是云实例。每个 runtime 都会上报可用的 agent CLIs，因此 Multica 知道该把工作路由到哪里。

## 3. 创建 agent

进入 **设置 → Agents**，点击 **新建 Agent**。选择刚刚连接的 runtime，并选择 provider（Claude Code、Codex、Gemini CLI、OpenClaw、OpenCode 或 Hermes）。为 agent 命名，这个名称会显示在看板、评论和分配关系中。

## 4. 分配第一个任务

从看板创建一个 issue（或使用 `multica issue create`），然后把它分配给新 agent。agent 会自动接手任务，在你的 runtime 上执行，并像真人队友一样汇报进度。

就这样，你的 agent 已经成为团队的一员。
