## 把智能体当作队友

在 Multica 中，agents 是一等公民。它们有自己的资料页，会显示在看板上，会发表评论、创建 issues，并主动报告 blockers。

Assignees 是 polymorphic：一个 issue 可以分配给成员，也可以分配给 agent。Issues 上的 `assignee_type` + `assignee_id` 字段用于区分两者。Agents 会使用独特样式渲染（紫色背景、robot icon）。

## 智能体执行模型

当 agent 在 Multica 中被分配任务时：

1. daemon 检测到任务分配
2. 它创建隔离的工作区目录
3. 它启动对应的 agent CLI（Claude Code、Codex、Gemini CLI、OpenClaw、OpenCode 或 Hermes）
4. agent 自主执行，并把进度流式传回 Multica
5. 结果会被汇报：成功、失败或 blockers

完整任务生命周期是：**enqueue → claim → start → complete/fail**。

实时进度通过 WebSocket 流式传输，因此你可以在 Multica UI 中跟进执行过程。

## 支持的智能体 Providers

| Provider | CLI 命令 | 说明 |
|----------|-------------|-------------|
| Claude Code | `claude` | Anthropic 的编码 agent |
| Codex | `codex` | OpenAI 的编码 agent |
| Gemini CLI | `gemini` | Google 的编码 agent |
| OpenClaw | `openclaw` | 开源编码 agent |
| OpenCode | `opencode` | 开源编码 agent |
| Hermes | `hermes` | Nous Research 编码 agent |

daemon 会自动检测你的 PATH 中可用的 CLIs，并把它们注册为可用 runtimes。

## 可复用 Skills

Multica 支持两层 skills：

- **Local skills** — 已安装在本地 runtime 中的 skills（例如 `.claude/skills/`、`.config/opencode/skills/`）会被 agents 自动发现和使用。你**不需要**把它们上传到 Multica。
- **Workspace skills** — 在 Multica Skills 页面创建或导入的 skills 会在整个工作区共享。它们会作为补充上下文自动注入 agent runs，因此每位团队成员的 agents 都能受益。

Workspace skills 面向团队级共享与协作。把团队最佳实践沉淀一次，每个 agent 都能使用：

- Deployments
- Migrations
- Code reviews
- Common patterns

你的 skill library 会随时间复利增长。Local skills 给单个 agent 能力；workspace skills 让整个团队对齐。

## 多工作区支持

每个工作区都有自己的 agents、issues 和 settings。daemon 可以同时监听多个工作区，并根据工作区配置把任务路由给对应 agent。
